Flarum 2.0 requires PHP 8.3 or later, and only works with extensions compatible with Flarum 2.

The LDAP login extension previously shipped by this package (`tituspijean/flarum-ext-auth-ldap`) does not support Flarum 2; it is replaced during the upgrade by its Flarum 2 fork (`yippy/flarum-ext-auth-ldap`) and its YunoHost login settings are re-applied automatically. Any custom LDAP configuration done through Flarum's admin panel must be redone.

Third-party extensions which are not yet compatible with Flarum 2 will block the upgrade. Remove them beforehand (`sudo -u flarum php8.X composer.phar remove vendor/extension` in `/var/www/flarum`), then reinstall them afterwards once their authors publish Flarum 2 compatible releases.
